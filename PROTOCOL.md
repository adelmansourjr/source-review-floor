# Source coverage under a bounded review budget

The decision is whether to ask one binary question about a three-project approval vector or to use an automated majority prediction. Data are historical Pabulib ballots from five sources with individual voter decisions. In the parent source transfer design, the first 32 shuffled ballots per target source select its top seven projects and fit a local model. The other four sources supply the equal-weight external prior. Each remaining target ballot supplies the labels for 35 project triplets. This follow-up reuses the established split and joint decision and query policy. The review response and noisy observation channels are simulated.

## Frozen design

- Each tape uses seeds 85715411 + 11 × dataset index + tape, with tape numbered 0 to 7. The base observation noise, tie keys, and 12% shared flips are sampled in that order for each source. Nominal observation and review accuracies are inherited from the parent. Two fixed stress conditions use 72% reviewer accuracy or shared report flips, with the same frozen decoder.
- Allocate exactly one review per selected ballot/triplet, with the total set to the floor of one quarter of all assessment cases. The three policies use the same estimated improvement in decision error, the same query for any selected case, and the same independent tie keys.
- **Global** allocates all reviews by descending estimated gain across sources. **Proportional** sets per-source quotas with Hamilton largest remainders, then chooses each source's highest gains. **Coverage floor** reserves each source's highest-gain cases to reach 20% coverage rounded up, then allocates remaining reviews globally by the same score. Under separable unit costs, this is an exact optimum for predicted gain with those coverage constraints. An independent exhaustive small-instance check tests the allocator.
- The primary endpoint is a practical joint gate under the nominal channel. Require the coverage-floor policy to raise the mean across tapes of minimum per-source coverage by at least 5 percentage points against the global policy, while increasing case-weighted expected decision error by at most 0.5 percentage points. The expected error integrates reviewer response randomness conditional on the observed ballot and report.
- Record case-weighted and equal-source decision error, minimum coverage, predicted gain per case, and per-source coverage and error for all three policies. Report paired changes for the eight tapes. The proportional policy and two stress conditions are descriptive. Every policy is assessed on the same scored cases on each tape. No policy selection post hoc.

The sources and historical labels were already available from the earlier pilot. The measurements describe these five fixed sources and the chosen simulation. The tapes quantify variability due to simulated report noise. Ballot triplets overlap and cross-fit models share data, so do not infer independent rows or population confidence intervals. Sources describe data collections, and coverage is an access-to-review proxy. Review effort is counted in binary questions.
